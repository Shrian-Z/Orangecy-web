1. **立意**：新增“产品立意（2026-10-24 改写）”。纯背单词机器，音乐是隐形弹药；
   双模式废弃，旧蓝白世界模型作废。PRD 与 v3 冲突的旧玩法描述作废。
2. **两色语义**：单白世界；白=学习骨架（底/面/留白），蓝=墨与音乐痕迹
   （歌词/目标词/音频控件/进度）。禁止整屏蓝底、阴影、第三色、渐变。
3. **导航**：启动直达学习页第一张卡；底部 4 个纯图标 tab（学习/复习/词书/我的）；
   后三个本轮占位；不允许歌门/词门/双模式/翻转/迷你条/播放层/NOW PLAYING/词义浮卡/CoverFlow。
4. **零废话**：原红线保留并加严为白名单——可见字只有数据 + 「模糊」「认识」；
   曲名、歌手、时间戳、说明字、空态解释全部不许出现。
5. **卡与音频**：全屏专注卡的结构、点击分区、0.2s 淡入淡出、0.5s 安静、
   静音跳声不跳时间轴、TTS provider 抽象，全部写成硬约束。
   SM-2、音源链路、歌词解析、词高亮明确“只迁移不重写 / 不动”。

## 需要你点头的 4 处

1. **文字颜色口径**：白=底/面/留白，蓝=墨 + 音乐痕迹，白底蓝字。
   若按“白=文字”字面执行会白底白字，故本稿把文字交给蓝墨。若你要别的，请指出。
2. **序号写法**：03 / 50，不写“第”。要“第 N / 总数”我改。
3. **TTS 淡入淡出**：浏览器 TTS 无法做增益斜坡；本轮用 0.2s 静默缓冲并如实报告，
   音乐片段仍是真 0.2s。或者改预渲染 50 词音频，能做真淡入淡出，但不是浏览器 TTS。
4. **“认识”实心蓝**：全页唯一大面积蓝。若严格执行“蓝只属于音乐”，可改蓝描边白底，
   代价是主判断弱一档。
