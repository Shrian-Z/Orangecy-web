# 主流背单词 App 的每日计划 / 限额 / 复习机制

日期：2026-10-25  
用途：Orangecy「学习计划 · 设置」的设计依据。只摘录与每日计划有关的结论，不复制任何产品文案 / 代码。

## 一、各家做法

### Anki

- Deck Options 有两个独立的每日上限：`New cards/day` 与 `Maximum reviews/day`。
- `New cards/day` 控制每天引入多少张新卡；少学或中断一天，第二天不会补发更多，仍按设置上限。
- `Maximum reviews/day` 是当天复习卡的上限；达到后不再显示复习卡，即使还有到期卡。
- 被上限拦下时，Anki 会在 congratulations 页面提示可以考虑提高上限，而不是让用户无路可走。
- Anki 明确提醒：新卡会暂时增加复习量；持续每天 20 张新卡，复习量大约会到每天 200 张。
- 结论：**新词和复习要分开限额；上限要可调；达到上限要有完成页和“是否加量”的出口。**

来源：[Anki Docs · Deck Options](https://docs.ankiweb.net/deck-options.html)

### 墨墨背单词

- 「每日学习量 = 当日复习单词量 + 当日新学单词量」。
- 默认顺序是「先复习、再新学」；复习按遗忘程度排序，新学按选词顺序 / 随机。
- 当日按学习量学完后，如果额外添加新单词，会立即安排、不受每日学习量限制，但会让后续复习量持续累积。
- 官方建议：先按自己的时间和精力确定每日新学数量，再添加单词，或重新调整每日学习量。
- 结论：**每日计划是一个整体（复习 + 新学）；额外加词是允许的，但要提示复习负担。**

来源：[墨墨百科 · 每日学习量](http://memodocs.maimemo.com/docs/PulqwOB1xi5jV0kb8Y1cPE7ZnKc)

### 百词斩

- 在单词界面进入「调整计划」，可以看到记单词数量，滑动选择目标数量，确认调整。
- 结论：**每日词量是“计划”而不是藏在某个角落的开关；入口应清楚、可随时调整。**

来源：[3DM · 百词斩设置单词数量方法](https://shouyou.3dmgame.com/gl/558662.html)

### 不背单词 / 扇贝

- 同类产品都把每日任务 / 学习计划作为独立设置，按计划推进新词与复习；计划可调整。
- 结论：与百词斩一致，**计划入口、当前词量、调整动作三者要在一起。**

来源：[不背单词学习计划设置方法](https://m.php.cn/faq/2658381.html)、[扇贝单词每日任务调整](https://www.php.cn/faq/2318877.html)

### Duolingo

- 每个学习者有 daily goal（每日目标），同时有 streak（连续天数）。
- Duolingo 曾把“达成每日目标”作为延长 streak 的条件；数据发现高强度目标反而降低坚持率。
- 后来把 streak 与 daily goal 分开：完成一节课就能延长 streak，daily goal 单独显示进度。
- 结论：**“今天有没有来”与“今天学了多少”要分开。完成态要肯定用户已经来了，再给继续加量的选择。**

来源：[Duolingo Blog · Improving the streak](https://blog.duolingo.com/improving-the-streak/)

## 二、共同模式

1. **每日计划 = 新词 + 到期复习**，两者都有上限，且上限可调。
2. **复习优先级高于新词**（墨墨默认先复习；Anki 可配置新/复习顺序）。
3. **上限不是死路**：到达上限有完成页；完成页提示还有多少到期、可以加量或明天继续。
4. **加量是“今天”的临时决定**，不应偷偷改掉长期设置；长期设置仍在计划/设置里。
5. **新词越多，未来复习越多**；设置页要给出这个预期。
6. **入口固定在“我的/设置/计划”里**，首页只显示今天的计划与开始按钮。

## 三、Orangecy 的落地选择

- 设置入口：**我的 → 设置 → 学习设置**，首页不放设置入口。
- 每日新词：5–100，默认 10，步长 5；快捷 10 / 20 / 30 / 50 / 100。
- 每日复习上限：0（不限）/ 100 / 200 / 300 / 500，默认 200。
- N / M：
  - N = min(newPerDay + 今日额外 − 今天首次学过的词数, 词书未学可放卡数)
  - M = min(今日到期可放卡数, reviewPerDay − 今天已复习数)
- 新词走完自动接到期复习；两钮仍可分别进入（完成态收起）。
- N=0 且 M=0 → 「今日完成」卡片 + 今日新学/复习数字 +「再学 10 个」。
- 「再学 10 个」只加今天的 `extraNew`，不改进设置，次日清零。
- 复习上限拦下的到期卡显示「X 个到期，明天继续」，次日重新进队，不丢。
- 新词设置页提示：「新词越多，后面到期的复习越多。建议先从每天 10–20 个开始。」

## 四、暂不做 / 后续

- streak、每日提醒、连续天数：Duolingo 证明有效，但需要通知/时区/补签规则，留到下一轮。
- 按词书单独设置：Anki 用 preset，Orangecy 当前只有一个全局设置；后续可做。
- 复习上限用尽时的「调整上限」快捷入口：当前需要去「我的 → 设置」，后续可在完成卡上加。
