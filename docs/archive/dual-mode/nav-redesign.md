## 结构

| 世界 | 标签栏（左→右） | 门的去向 |
| --- | --- | --- |
| 蓝世界 · 歌模式 | 词门 / 罗盘 / 搜索 / 头像 | 词门 → 今日词卡 |
| 白世界 · 词模式 | 歌门 / 词卡 / 复习 / 头像 | 歌门 → 播放层（升起态） |

- 迷你条：两模式同一条，固定在标签栏上方。无曲目时整条隐藏；首次播放后出现。
- 播放层：全屏层，不占 tab、不占页面历史。层内无标签栏、无迷你条、无顶栏。
- 标签页：无顶栏，内容从屏幕最顶端开始；标签栏**贴视口底边**（含 safe-area），不悬浮、不做顶部导航。迷你条固定在标签栏上方 10 px。
- 搜索 / 账号维持抽屉入口，标签槽只负责开门，不新增页面。
- 六个入口映射：播放（层 + 迷你条）/ 搜索 / 推荐 / 词卡 / 复习 / 账号。蓝世界没有独立“播放”tab，播放入口由迷你条承担。

## 形状与材质

- 移动端：390 宽参考；标签栏贴底，高 62 px + safe-area；迷你条 56 px，固定在其上方 10 px；迷你条左右各 12。
- 迷你条：封面 36 × 36，连续曲率；♪ 16；曲名 13 / 单行截断；播放键 36。
- 标签栏：四等分槽位，纯图标；门芯片 46 × 33；图标 21；到期点 4 px。
- 连续曲率用于迷你条、门芯片、封面缩略。Chrome 151 已支持 `corner-shape: squircle`，实现优先用它；不支持时降级 `border-radius`，不改变结构。
- 材质 A（默认）：模式色高不透明度 + `blur(28–30px)`；蓝世界 `rgba(0,47,167,.78–.82)` + 白字；白世界 `rgba(255,255,255,.84–.86)` + 蓝字。1 px 反色边线定位，**不用阴影**。
- 材质 B（守卫兜底）：纯 `#002FA7` / `#FFFFFF` 填充，去掉 blur；框、位置、内容完全不变。
- 激活态：当前页图标全亮；其余同色降明度（蓝世界 45% 白，白世界 40% 蓝）。不铺激活底、不写文字。
- 门：永远倒色——蓝世界白芯片，白世界蓝芯片。永远最左。
- 到期点：4 px、无数字、无动画。蓝世界挂词门；白世界挂复习图标。

## 行为

### 开层 / 收起

- 点迷你条条身（右侧播放键除外）→ 播放层自底升起，350 ms；播放键只切播放/暂停，不冒泡。
- 层收起只认左上 `⌄`；不做下滑手势，不与歌词滚动抢手势。
- 收起后回到出发页 + 出发模式，并保留该页滚动位置。
- 从白世界进入播放层，收起后仍是白世界原页；从蓝世界进入，收起后仍是蓝世界原页。
- 播放层内点词白卡、暂停浮现既有胶囊、chrome 闲置 5 秒隐去，全部沿用现有逻辑。
- **层内既有播放胶囊保留**：它属于舞台内控制，不占“层 chrome 只有两件”的名额；两件指左上收起柄、右上词门。

### chrome

- 只有两件：左上收起柄 `⌄`、右上词门（倒色芯片）。
- 点空白唤出；闲置 5 秒一起淡出。点词仍优先开白卡，不误触 chrome。
- 右上词门 → 收起层并去今日词卡；到期点跟随词门。

### 世界翻转

- 点门：整屏蓝↔白翻转，约 300 ms，从门那一侧（左）翻入；轴向门侧。
- 门的位置不漂移，翻面时从词门换成歌门（或反向）；不叠阴影，避免第三色。
- 减少动态效果 / `prefers-reduced-motion`：翻转为 0 ms 瞬时。
- 白 → 蓝经歌门：300 ms 翻转与 350 ms 升层同拍；收起时反向落回原页与原模式。

### 启动进入

- 设置新增“启动进入”：只放两颗微缩门芯片（白=词卡，蓝=歌）。默认蓝（歌模式）。选中态用一圈 1 px 蓝环，界面不写“启动进入”。
- 本稿暂按 **A 方案** 画：有当前曲 → 直接进播放层；无曲 → 落推荐、迷你条隐藏；白模式启动 → 词卡。
- 备选 **B 方案**（更贴 Apple Music）：启动始终落推荐 / 词卡，播放层只由条或歌门手动升起；点推荐歌只出现迷你条，不自动升层。

### 无曲目 / 首次播放

- 无曲目：启动落推荐页，迷你条隐藏；标签栏仍在。
- 首次播放后迷你条出现；不改变所在页。
- 音乐跨层、跨模式不断；升层、收起、翻转都不打断音频。

### 到期点

- 由 `due > 0` 控制；4 px 蓝点，挂词门（蓝）或复习（白）。
- 不显示数字、不做 pulse，不因激活态改变尺寸。

## 不破映射

- 播放：层 + 迷你条，不新增 tab。
- 搜索 / 推荐 / 词卡 / 复习 / 账号：固定标签位，图标沿用搜索、罗盘、层叠卡、回转箭头、头像；账号仍是抽屉。
- 点词白卡、暂停胶囊、chrome 隐藏逻辑：原样。
- 播放舞台内部布局（歌词排版、封面形态）：下一轮 ④ 再动，本轮不改。
- 两色系统：新增组件全部走集中变量；无渐变、无黑影、无第三色。
- 词卡手势：去掉移动端固定评分条，评分并回卡片流；底部为导航预留宽度，不让条盖住可点区。
- 移动端同构：同一套层 / 条 / 栏，仅尺寸与留白收窄。
