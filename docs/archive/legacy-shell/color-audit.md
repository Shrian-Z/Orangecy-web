## 4. 建议的新色板

只保留 2 个原始色值，全部其余颜色由透明度派生：

```css
:root {
  --blue: #002FA7;
  --white: #FFFFFF;

  /* 白世界：克莱因蓝系 */
  --blue-60: rgba(0, 47, 167, 0.60); /* 次要文字 */
  --blue-40: rgba(0, 47, 167, 0.40); /* 焦点环 */
  --blue-30: rgba(0, 47, 167, 0.30); /* 占位 / 禁用 / 遮罩 */
  --blue-10: rgba(0, 47, 167, 0.10); /* 分割线 / 描边 */
  --blue-08: rgba(0, 47, 167, 0.08); /* 次级按钮底色 / 阴影 */

  /* 蓝世界：白色系 */
  --white-60: rgba(255, 255, 255, 0.60); /* 次要文字 / 焦点环 */
  --white-45: rgba(255, 255, 255, 0.45); /* 已唱过的词 */
  --white-25: rgba(255, 255, 255, 0.25); /* 未唱 / 进度槽 / 遮罩 */
  --white-10: rgba(255, 255, 255, 0.10); /* 线 / 次级按钮底（新增派生阶） */
}
```

- **新增派生阶只有一个：`--white-10`**，用于蓝底上的分割线和次级按钮底，按同一规则补，报备。
- 蓝世界歌词：正在唱 `--white` + 多层白色辉光；已唱 `--white-45`；未唱 `--white-25`。
- 主按钮：白世界蓝底白字；蓝世界白底蓝字。两处都用实底，不用渐变。
- 阴影：白世界最多 `--blue-08`，蓝世界不用阴影（歌词辉光除外）。
- 圆角：矩形表面只用 `10 / 16 / 22px` 三档；圆形头像/图标按钮保留圆形。
- 字体：全站系统字体栈；大标题 300–400，正文和按钮 500；删除 serif 字体引用。
- 动效：200–300ms，轻微回弹；世界切换用背景色/文字色整屏过渡，不使用渐变画面。

## 6. 必删清单

- 48 处渐变（linear / radial / conic），包括所有按钮渐变、进度条渐变、骨架屏渐变、扫光。
- 所有黑色阴影、黑色 text-shadow、黑色 mask、`#111`、深色 spinner；以及 `rgba(22,22,26,…)` / `rgba(28,28,33,…)` 中性灰。
- 封面取色氛围层：`Ambient.tsx` 整层、`.ambient-*`、`.cover-glow`、`.cover-reflection`、`.immersive-bg`、`cover-veil` 的黑/白渐变。
- `LyricAura` Canvas 的橙、暖橙、紫蓝、暖白粒子。
- 四平台各自的淡蓝色相与发光，统一为蓝/白 + 文字/图标。
- 生成式随机 HSL fallback、`--green` / `--danger` 语义色、暖白 text-shadow。
- 旧的午夜蓝、天空蓝、雾白、冰蓝强调色和整套旧 CSS 变量。

保留：专辑封面、用户头像、歌词文字本身（内容）；封面图像可以在 UI 中显示，但不得再拿它生成背景光或染色。

## 7. 需要你拍板的一件事：二维码

登录二维码是平台/服务端生成的图像，源码里没有色值，但图像本身通常包含黑色模块、白底，甚至平台彩色 logo。它不属于 CSS 可清理范围。

严格按“全站只允许两个色值”，建议做：

- 写一个 `ThemedQRCode` 组件，把二维码图像画到 Canvas，按亮度二值化：深色模块 → `#002FA7`，浅色 → `#FFFFFF`；
- 或者自己用二维码库生成蓝/白码，网易云/波点可这样做，QQ/酷狗需要确认原始 key 是否可复用。

风险：要实测扫码，尤其平台 logo 和抗锯齿。若你不想冒风险，也可以把二维码列为“功能性内容例外”，只保证外框、说明、状态都是蓝白。

## 8. 两页验收标准（下一步）

先只改：

1. **播放舞台（蓝世界）**：纯 `#002FA7` 平铺；无氛围光/取色；歌词在蓝底上浮起；正在唱白色 + 辉光，已唱 45%，未唱 25%；封面作为唯一允许的彩色内容；控件收敛。
2. **词卡（白世界）**：纯白平铺；文字全蓝；大单词细字重；靠留白分组；评分按钮只靠蓝 8% 底和文字/图标区分；无黑影、无暖光、无彩色状态。

两页都通过后，再按本清单铺到搜索、队列、推荐、词书、登录、设置、移动端，并加一个色值检查脚本，最后再给你一次全项目扫描结果。
