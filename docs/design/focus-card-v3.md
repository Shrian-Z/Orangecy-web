- **蓝 = 墨 + 音乐的痕迹**：骨架字/图标用蓝墨；歌词、目标词、音频控件、进度是“音乐的痕迹”。

- 无 box-shadow / text-shadow；焦点只用 2px outline @40%。
- 无封面、无二维码、无图片；本轮没有内容豁免，所有像素走蓝白。

## 音频序列（每张卡的时间轴）

| 相对时间 | 事件 | 界面 | 音频 |
| --- | --- | --- | --- |
| 0 | 卡片翻入 | 内容 280ms 淡入 + 下移归位 | 无 |
| 320ms | 翻入结束 | 静止 | 无 |
| 520ms | 片段开始 | 进度 0；第一句按 timestamp 点亮 | seek 到 start；volume 0；play |
| 520–720ms | 淡入 | 进度开始走 | volume 0 → 1，线性 200ms |
| 句 timestamp | 逐行点亮 | 当前句 100%，下一句 34% | 继续 |
| end-200ms | 淡出开始 | 进度约 97% | volume → 0，线性 200ms |
| end | 片段结束 | 进度 100% | pause；volume 0 |
| end+500ms | 安静结束 | 静止 | 开始单词发音 |
| 发音结束 | 静场 | 停在卡片，等用户回想 | 无 |
| 判断 | 切卡 | 旧卡淡出 | 若有声，先 200ms 淡出；取消发音 |

- 片段规则：≤2 句、播一遍即止、0.2s 淡入 / 0.2s 淡出、结束留 0.5s 安静。
- 静音：不调用音频；同样的 320 + 200 + 片段时长 + 500 时间轴照走；发音阶段跳过。
- 手动重听：取消当前序列，seek 回 start，0.2s 淡入；播完即停，不再自动发音、不切卡。
- 手动发音：先把片段 0.2s 淡出并暂停，再发音；不切卡。
- 判断：先把片段/发音停掉（片段 0.2s 淡出），再切卡；新卡从 0 开始。
- 首启自动播放被浏览器拦截：第一次 pointerdown/keydown 解锁后，若当前卡还在片段阶段，从当前位置 0.2s 淡入补播；不弹任何提示。
- 切 tab 离开学习页：0.2s 淡出并暂停；回来重开当前卡序列。

## 发音 provider

接口（实现时落在 src/audio/pronunciation.ts）：

    type PronunciationProvider = {
      speak(word: string, opts: {
        signal?: AbortSignal;
        onStart?: () => void;
        onEnd?: () => void;
        fadeIn?: number;
        fadeOut?: number;
      }): Promise<void>;
      cancel(): void;
      supportsGainRamp: boolean;
    };

- 本轮 browserTtsProvider：speechSynthesis，en-US，rate 0.86，cancel 后再 speak；
  onend 或 3s 超时收口。supportsGainRamp = false。
- 后期 recordedAudioProvider：播放真人音频包，audio + volume ramp，supportsGainRamp = true。
- **需要你确认的技术限制**：浏览器 TTS 的输出无法接 Web Audio 增益，做不了真正的 0.2s 音量斜坡；
  手动重听/判断打断 TTS 时也只能 cancel，无法淡出（音乐片段仍 0.2s 淡出）。
  本轮用 0.2s 静默缓冲包住发音，并在交付报告里如实标注；音乐片段仍然是真 0.2s 淡入淡出。
  若要发音也严格 0.2s 淡入淡出，本轮可改为“预渲染 50 词音频 + audio 淡入淡出”，但就不是浏览器 TTS 了。

## 边界状态

- 词表加载：页面中央一个 4px 蓝点呼吸，无文字；就绪后第一张卡翻入。
- 词表失败：中央一个 RotateCcw 图标，18% 蓝，可点重试；无文字、无 toast。
- 50 张走完：中央一个 RotateCcw 图标，18% 蓝，点一下从第 1 张重开；无“完成”文案。
- 首启自动播放被浏览器拦截：时间轴照走、无声；第一次 pointerdown/keydown 后从当前位置补播。
- 短屏（<700 高）展开：卡片内部滚动，判断按钮固定在卡片底部，不被遮。
- 减少动态效果：切卡、展开、呼吸归零；音频 0.2s 淡入淡出保留。
- 页面切走 / 切 tab：0.2s 淡出并暂停；回来重开当前卡序列。

## 为什么这样砍

- 音乐隐形是立意级红线：封面、曲名、歌手、播放键、队列、推荐、搜索全部退场；
  只留歌词、目标词、进度、静音四个“痕迹”。
- 词义只在卡内展开：不再做白卡浮层，不再有“点词看释义”的第二层；
  用户不需要在词典页和舞台之间来回。
- 白底单世界：没有蓝白翻转、没有两套标签栏、没有门；
  打开就是一张卡，判断完就是下一张。
- 只留两个判断词：模糊 / 认识；不认识的词交给下一轮复习卡，不在学习页展开三档。
- 留白是主设计：没有卡片边框、没有阴影、没有仪表盘；层级只靠蓝的明度和一个实心按钮。

## 需要你点头的 4 处

1. **文字颜色口径**：白=底/面/留白，蓝=墨 + 音乐痕迹；白底蓝字。若你要字面意义上的“白字”，请指出。
2. **序号写法**：顶部只写 03 / 50，不写“第”。零废话优先；要“第 N / 总数”我改。
3. **发音淡入淡出**：浏览器 TTS 无法做增益斜坡；本轮 0.2s 静默缓冲 + 如实报告，音乐片段仍是真 0.2s。
   或者改为预渲染音频（可做真淡入淡出，但不是浏览器 TTS）。
4. **“认识”实心蓝**：这是全页唯一的大面积蓝。若严格执行“蓝只属于音乐”，可改成蓝描边白底；
   代价是主判断弱一档。
