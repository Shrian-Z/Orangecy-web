## 还需要人工完成的验收

### 1. 网易云扫码登录（M1 的最初三件事）

1. 打开 <http://127.0.0.1:8790>，点右上角平台胶囊 → 网易云「登录」。
2. 用网易云 App 扫码，确认弹窗进入成功态。
3. 回到播放器，确认「接入检查」变成 3/3。
4. 点歌词任意一句，确认从该秒开始播放。

当前状态：二维码生成、等待扫码已验证；没有可用账号扫码，所以仍显示 2/3。

### 2. QQ / 酷狗 / 波点会员曲

分别从平台账号中心扫码，然后各选一首 VIP/会员曲，确认：

- 播放器拿到的是完整曲，不是 30 秒试听；
- 进度能走到副歌；
- 歌词/逐词/目标词正常。

当前状态：免费曲和逐词已验证；会员曲路径代码已接，缺人工扫码。

### 3. 真机 60 帧

在旧 Android / iPhone 上打开生产地址，播放带逐词高亮的歌，观察：

- 歌词滚动是否稳定；
- 封面飞入、沉浸页是否掉帧；
- 若掉帧，打开平台账号抽屉 →「减少动态效果」再测一次。

当前状态：只有 Chrome CPU 限速模拟，没有真机数据。

## 已知限制

- 波点播放仅限中国大陆网络；会员曲需要登录。
- 网易云/QQ/酷狗是社区非官方接口，商用前必须单独评估授权和版权。
- 推荐池是有限池（40 首），不扫全曲库；歌词只缓存命中句。
- 完整 Pixi/R3F 歌词舞台未做；当前是 Canvas 氛围层 + DOM 歌词 + 逐词高亮。
- 网站版换浏览器/清缓存会丢本机学习进度，符合 PRD 的 MVP 约定。
